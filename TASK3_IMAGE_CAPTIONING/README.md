# Image Captioning AI

This project generates captions for images using a pretrained ResNet50 model.

## Features
- Image recognition
- Caption generation
- Pretrained ResNet50 model
- Simple NLP-based caption output

## Technologies Used
- Python
- TensorFlow
- ResNet50
- NumPy
- Pillow

## How to Run

```bash
python image_captioning.py
```
