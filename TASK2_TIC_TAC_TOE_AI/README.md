# Tic-Tac-Toe AI

This project is a simple Tic-Tac-Toe game developed using Python where a human player competes against an AI player.

## Features
- Human vs AI gameplay
- Minimax algorithm
- Unbeatable AI
- Console-based interface

## Technologies Used
- Python
- Minimax Algorithm

## How to Run

```bash
python tic_tac_toe.py
```
