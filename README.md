# CODSOFT Artificial Intelligence Internship

This repository contains all tasks completed during my Artificial Intelligence Internship at CODSOFT.

## Tasks Completed

### Task 1 - Rule Based Chatbot
A chatbot that responds using predefined rules.

### Task 2 - Tic Tac Toe AI
An AI-powered Tic Tac Toe game using the Minimax algorithm.

### Task 3 - Image Captioning
Image caption generation using ResNet50.

### Task 4 - Recommendation System
Movie recommendation system using content-based filtering.

### Task 5 - Face Detection and Recognition
Face detection and recognition using OpenCV and Haar Cascade.
